# Definitions: Person Domain

This document defines the Ubiquitous Language for the People management domain.

## Core Terms

- **Person**: An individual who can be involved in a debt relationship. This is the root entity of this module.
- **Identity**: The unique technical identifier (ID) that distinguishes one person from another.
- **Contact Info**: The set of data used to reach a person, including their email and phone number.
- **Full Name**: The complete name used to identify a person in the ledger.
- **Archived State**: A status indicating that a person is no longer active in the system but their historical data is preserved.
- **Soft Delete**: The process of moving a person to an **Archived State** instead of removing their data from the Store.
